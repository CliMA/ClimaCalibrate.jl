Calibration report

ClimaCalibrate provides utilities for reporting the state of each iteration of a calibration. This is implemented with a CalibrationReport which is built from AbstractReporters such as

  • WalltimeReporter for reporting the walltime information,
  • TimestepReporter for reporting the timesteps taken,
  • ErrorReporter for reporting the error metrics,
  • ParameterReporter for reporting the parameter trajectory,
  • and EnsembleReporter for reporting the state of the ensemble.

Example

You can build a CalibrationReport by passing a tuple of AbstractReporters to the reporters keyword argument.

import ClimaCalibrate.Report as Report

reporters = (
    # Estimate the remaining walltime for a calibration of 10 iterations
    Report.WalltimeReporter(10),
    Report.TimestepReporter(),
    Report.ErrorReporter(; error_metrics = ["loss", "unweighted_loss"]),
    Report.ParameterReporter(),
    Report.EnsembleReporter(),
)
calibration_report = Report.CalibrationReport(; reporters)

Implementing your own AbstractReporter

To write your own reporter, subtype AbstractReporter and add a method to report, and optionally to title.

import EnsembleKalmanProcesses as EKP
import EnsembleKalmanProcesses.ParameterDistributions as PD
import ClimaCalibrate.Report as Report

struct YourReporter <: Report.AbstractReporter end

function Report.report(
    io::IO,
    reporter::YourReporter,
    ekp::EKP.EnsembleKalmanProcess,
    prior::PD.ParameterDistribution,
    output_dir,
)
    println(io, "Your report")
end

# Optional to implement
Report.title(reporter::YourReporter) = "Your section title"

calibration_report = Report.CalibrationReport(;
    reporters = (Report.ErrorReporter(), YourReporter()),
)

The sections of the report are in the same order as the reporters passed to CalibrationReport.

How are reports generated?

The arguments to report are

  • io: Where to write the section. Write to io with print or println instead of logging with @info or printing to stdout, so that the section is part of the report.
  • ekp: The EnsembleKalmanProcess after the update of the current iteration.
  • prior: The ParameterDistribution of the calibration.
  • output_dir: Directory to write logs or plots to.

CalibrationReport prints the title of the section and indents the lines below it, so a reporter should not print its own title or indent its lines. Also, report is called once per iteration, after ekp is updated with the forward model output of that iteration.
